Accepted 2026-10-27 for development implementation and production preparation. Preserve `packages/server-<owner>/src/{domain,application,adapters,public}`. Cargo privacy and explicit public facades enforce owner boundaries; architecture checks enforce inward domain/application dependencies within each crate. Application ports own effects, adapters implement them, and composition roots connect owners. Commands that require atomic cross-owner behavior retain a single transaction.
