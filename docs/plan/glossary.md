# Glossary

Canonical glossary lives at repo root `CONTEXT.md` (code-derived, glossary-only).

See `CONTEXT.md` for all terms. This file exists so `docs/plan/` is self-contained for readers who start here.

### Staff self-service

- **Overtime Request** — A Company-scoped request by an Engagement for planned overtime authorization or retrospective review.
- **Overtime Actuals** — Worked time and unpaid breaks, subject to manager verification and independent HR approval; distinct from planned authorization.
- **Payroll Handoff** — A uniquely linked approved-hours contribution to payroll preview, with no implied payment authority or statutory pay calculation.
