# Billing Sandbox operations

- Customer: `/holdings/acme/settings?section=usage`. Platform: `/platform/billing`.
- Schema: control migration `0009_billing.sql`. Private evidence: `<ERPX_DATA_DIR>/files/platform-billing`, never a static asset path.
- Run the durable jobs process with the same Sandbox keys and control database as the app. The independent 30-second `billingWork` loop closes due periods, applies queued service changes, issues approved invoices, drains signed event inboxes and reconciles stale open invoices. Its successful passes update the `runtime_health` billing heartbeat, independently of other modules. Do not change the machine clock or manually close an active customer month.
- Enable `invoice.*`, `payment_intent.*`, `setup_intent.*`, `checkout.session.completed`, `customer.subscription.*` on the test webhook. Endpoint: `/api/v1/stripe/webhook`. Persist before acknowledgment; failures retain inbox entries and retry. Stripe does the card collection retries.
- Approval requires a closed service month and an explicit cost-completeness review. THB integer satang; manual due date is seven days from finalization. Auto-pay requires saved card + consent. Withdrawal disables future automatic collection, but cannot reverse a payment already processing at Stripe.
- To correct unpaid issued amounts: Void, wait for Stripe confirmation, edit the released costs, mark review complete and approve again. Paid amounts are immutable; record an adjustment with an original invoice reference. Net credits require manual reviewed Stripe credit-note handling; automated refunds are outside scope.
- Jobs in `attention` are shown in Platform Billing. Retry transient failures with the existing job/Stripe keys. `IDEMPOTENCY_WINDOW_EXPIRED` intentionally refuses automated retry: locate the Stripe invoice by metadata `erpx_invoice_id`, reconcile missing local progress against its lines, and only resume after review. Do not create another invoice to resolve an ambiguous timeout.
- Evidence uploads accept signature-checked PDF/PNG/JPEG, max 5 MB, served as private attachments only to Platform billing roles. Customer URL guessing cannot access them.
- Sandbox tests use isolated database fixtures and injected clocks. No test changes the host clock or backdates the actual Holding enrollment. The sample total 925 baht is Hosting 300 + Storage 50 + provider-funded AI 75 + Standard Support 500 for a full month.

No Live keys, Live events, taxes, coupons, annual billing, automated refunds, automatic Finance posting, actual access restrictions or data deletion are supported by this offering.
