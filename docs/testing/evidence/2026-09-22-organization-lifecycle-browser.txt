ERPX Release 1: usable reviewed organization changes
Date: 2026-09-22 (Asia/Bangkok)
Environment: isolated Demo Company, run 93219d8e2062; real owner services and PostgreSQL persistence

Problem and change
- The proposal form used FormData without the submitter. Save draft and Submit for review therefore lost their mode and addressed an unsupported command route. The actual submitter is now included, with draft as the safe implicit-submit default.
- Successfully saved new proposals clear their inputs; failed commands retain the entered values. Existing proposal/unit forms remount only when their authoritative revision changes.
- The old last-100 mixed queue hid applied/cancelled requests. Company administrators now have a 20-item paginated list with status filters and literal name/reason search, plus immutable decision history showing names, revisions, times and reasons.
- Company review evidence is unavailable to ordinary staff, scoped HR assignments and branch/department workspaces. The Company command guard enforces the same workspace boundary.
- An account linked to the requester's person cannot independently approve the request. Review controls use the server-derived permission decision.

Each scenario uses an independent Holding owner, Company HR reviewer and ordinary employee:
1. Save a branch draft, reload, then submit it through the real form.
2. Reviewer returns it with a reason. Requester corrects the name/reason and resubmits; independent approval applies revision 5.
3. Filter Applied and open all five immutable decision events, including the original rejection and final decision.
4. Rename the branch, create its child department and approve both independently.
5. Attempt to suspend the branch while its child department is active: HTTP 409, visible dependency explanation, unchanged active branch and pending request. Requester cancels; Cancelled filter retains it.
6. Suspend the department, suspend the branch, reactivate the branch and then the department through separate reviewed requests.
7. Ordinary employee sees no Company change queue or request evidence from the protected overview API.
8. Search the completed/cancelled branch history after reload.
