ERPX shared workspace header: usable narrow-screen context and controls
Observed: 2026-09-22 (Asia/Bangkok)
Environment: isolated Demo dda6158fd76f plus read-only public verification.

Delivered
- At widths up to 1000px, workspace/brand, search and active-role controls occupy the first header row; breadcrumb/current-page context occupies a separate second row.
- Compact breadcrumb text can shrink and truncate within its own row. The overflow path control is 44px wide, retaining ancestor navigation and Escape focus restoration.
- Loading the workspace chooser uses a disabled trigger with the same layout instead of an unconstrained text fallback.
- Shared focus scroll margins and organization/chart anchors adapt to the taller header so linked records remain visible.
- Branch/department labels resolve the authorized current Company name from its organization node when the Company list is absent. The Holding name is no longer presented as the Company name in scoped workspaces.
