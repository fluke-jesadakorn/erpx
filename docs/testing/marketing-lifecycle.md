# Marketing lifecycle simulation

สถานะนี้เป็น owner implementation บนข้อมูลจำลองสำหรับ S01/S16 และ G01/G15. Form, content, domain และ provider readiness ต้องผ่าน independent activation; preview ไม่ถูกนับเป็น active. Lead candidate snapshot form version, consent, attribution และ brief; engagement เป็น immutable evidence. Reviewer ส่งต่อเข้า `createCRMLead` ของ CRM จริงด้วย idempotency แทนการคัดลอกปลายทางเอง

หลักฐาน service regression 14 tests ใน `docs/testing/evidence/2026-09-21-marketing-tests.txt` ครอบ owner flow, CRM regression, Work views และ migration replay. Regression ล่าสุด 10 tests ปิดเพิ่ม consent guard และ campaign summary. เพิ่ม partial browser acceptance ของ consented lead → CRM handoff ใน [หลักฐาน 2026-09-23](evidence/2026-09-23-marketing-to-crm-browser.txt): ผู้สร้าง form/candidate กับผู้ activate/ส่งต่อแยกจากกัน และ browser ตรวจ CRM detail, attribution, brief, owner, API และยอด campaign/source หลัง reload. Form ต้องประกาศ `consentRequired: true`; เพิ่มรายงาน aggregate ของ captured/pending/CRM handoff/rejected โดยไม่ส่ง contact details และกรองตาม branch/department. แก้ ID suffix ให้ URL-safe เพื่อให้ link เปิด CRM detail ได้จริง. ยังเหลือ public hosting, email/provider webhooks, bounce/unsubscribe, provider delivery analytics, browser acceptance สำหรับเส้นทางอื่น, provider/production และ Company business acceptance.
