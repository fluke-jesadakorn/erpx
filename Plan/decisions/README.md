# Future-State Decision Register

Future-State Decisions establish accepted target authority where current code
and contracts do not yet exist. They do not claim implementation.

| FSD-002 | [Shared platform capabilities](FSD-002-shared-platform-capabilities.md) | Accepted | Product Council | Architecture, Security, Privacy, Operations, UX |

| FSD-005 | [Collaboration, references, and agents](FSD-005-collaboration-references-and-agents.md) | Accepted | Product Council | Architecture, Security, Privacy, Operations, UX |
| FSD-006 | [Clean rebuild architecture and atomic cutover](FSD-006-clean-rebuild-architecture-and-cutover.md) | Accepted | Architecture Council | Product Council, Domain Owners, Security, Operations, UX |

An accepted FSD remains authoritative until an ADR or later FSD explicitly
supersedes it.
