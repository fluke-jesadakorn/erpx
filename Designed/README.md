# ERPX design references

The current application and [owner contracts](../docs/contracts/next/README.md) define implemented behavior. This directory contains the [clickable mockup](mockup/README.md) and earlier visual studies; mockup state and actions are local simulations, not Company authority or acceptance evidence.

Use the [current product brand guide](../docs/brand/ERPX-brand-guide.md) and SVG masters in `public/brand/` for delivered UI. Alternative branding kits are retained design work, not alternative active Product Brands. The [33-module catalogue](../docs/contracts/next/catalogue.md) replaces the removed Rust-era domain maps.

Canvas operations, if a `.pen` is introduced again, follow [Designed guardrails](AGENTS.md). Earlier canvases remain recoverable from Git history; do not recreate or parse them as part of documentation maintenance.
