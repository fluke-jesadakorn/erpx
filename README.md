# ERPX

ERPX is an operations platform for organizations that manage finance, purchasing, inventory, field service, and other work across companies and teams.

- [Run the Service Count demo](docs/start-here.md) with fictional data in a local Dev Container.
- [Find the code for a change](docs/find-the-code.md) and run the test for your first contribution.
- [Contribute to ERPX](CONTRIBUTING.md) for the PR workflow and review rules.

## Project status

ERPX uses Next.js for its applications and PostgreSQL for data. Business workflows are moving from TypeScript to a Rust modular monolith. The [documentation index](docs/TOC.md) links to architecture, current migration status, and verification.

For the host development setup, use the [local development guide](docs/development.md). See [licensing](docs/community/LICENSING.md) and [security reporting](.github/SECURITY.md) for project policies.
